# YouTube Catppuccin

Catppuccin for YouTube: the main site, YouTube Studio, YouTube Music, the mobile site and players embedded in other websites.

## How the flavor is chosen

The style follows YouTube's own Appearance setting: Dark Flavor when YouTube is dark, Light Flavor when it is light. YouTube Music has no light theme and always takes the Dark Flavor.

## Settings

| Setting | Default | Notes |
|---|---|---|
| Light Flavor | Latte | |
| Dark Flavor | Mocha | |
| Accent | Mauve | Takes the place of YouTube's red: the logo, the progress bar, the subscribe button and selected items. |
